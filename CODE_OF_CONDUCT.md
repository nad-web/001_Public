# Code of conduct

Be respectful, specific, and constructive. Welcome different backgrounds and experience levels. Critique code and decisions rather than people. Do not harass, discriminate, publish private information, or misrepresent another person’s work.

Keep feedback focused on the project. Explain problems with reproducible examples and suggest improvements when possible. Credit original authors, asset creators, and contributors.

The repository owner may edit or remove inappropriate content and restrict participation when needed. For conduct concerns, use a private channel listed on the owner’s public GitHub profile when available; do not publish personal information in an issue.
