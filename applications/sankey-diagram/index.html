Create & edit

Add connections in Data, or import rows with source, target and value columns. New names create nodes automatically. Use Nodes & colours to rename and recolour them. Select a ribbon to edit its colour.

Arrange & explore

Drag a node vertically. Keyboard users can focus a node and press ↑ or ↓ (hold Shift for larger steps). Use zoom buttons to inspect details and Fit to see the full chart. Auto layout resets manual positions. Ctrl/⌘ Z undoes; Ctrl/⌘ Shift Z redoes.

Save & export

Download Project JSON for a fully editable backup. SVG keeps text and shapes sharp. PNG supports transparency; JPEG uses a solid background. Large raster exports are limited to 16 megapixels. PDF uses the browser’s print dialog. A Share button is provided for supported devices.

Honest data

Up to 120 nodes and 300 flows. Values must be finite and nonnegative. Circular connections and self-links are rejected. Zero-value flows remain in your data but are not drawn. Unequal incoming and outgoing totals are reported; no balancing flows are invented. Very small ribbons or long labels may need a larger canvas.

Your data & offline use

Nothing is uploaded. Data stays in this browser and does not synchronise between devices. Export backups before switching browsers or installing. Once the offline-ready message appears, the editor and exports work without a connection. Browser storage may be cleared, so keep project backups.

Install on iPhone

Open in Safari, tap Share → Add to Home Screen, enable Open as Web App if shown, then Add. Open the Home Screen icon online once and wait for offline preparation.
