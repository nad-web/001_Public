# Updating apps

Open the app online after deployment. Apps with a waiting worker offer an explicit reload/update control. Export important edits before reloading. If an old installed shortcut remains, close open tabs and reopen online.

Readiness is per app. Math saves core lessons/graphics first; selected clips are saved explicitly. Device storage can be cleared or evicted, so readiness is not permanent storage protection. The old root/game workers remove only their own obsolete caches; Sankey's worker is unchanged.
