# Maintain the library

Every app has an independent folder and README. [Browse the generated list](../applications/README.md). [Add a future app](ADD_APP.md), [upload the repository](MIGRATION.md), and review [actual validation](VALIDATION.md).

Create a lowercase app folder with index.html and local browser-ready files, implement the main task and error states, preserve licenses, and test desktop/phone behavior. Commit to main; the existing workflow discovers and publishes it. App metadata is local; portfolio.json describes the developer rather than serving as an app registry.
