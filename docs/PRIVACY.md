# Privacy and local data

These static apps have no application accounts, analytics or cloud database. GitHub Pages serves the files under its own hosting policies. Records remain in the browser/profile and are not synchronized to other devices. Export important data. Clearing site data can remove records and offline files. Installed iPhone web apps can use separate storage.

Clipboard, notifications, speech, downloads and installation depend on the browser and user choices. Math/Memory narration files are local. German practice can use the device speech engine, whose availability and offline behavior depend on installed voices. External source/license links need network access.

Do not put private API keys or personal production records in a public repository. Future apps needing authentication, private data or server secrets require a suitable backend and privacy design.
