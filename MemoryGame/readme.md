# باغ حافظهٔ هاینبورگ

**ساختهٔ نورالله عادل · نسخهٔ ۱.۱.۰ · ۲۰۲۶-۱۰-۳۱ · دری / فارسی**

بازی جفت‌کردن کارت‌ها با عکس واقعی هاینبورگ در هِسِن آلمان، متن راست‌به‌چپ، رقم‌های فارسی و گفتار فارسیِ ذخیره‌شده در خود بازی.

## بازی و نصب روی آیفون

پس از انتشار مخزن، بازی در این نشانی قرار می‌گیرد:

https://nad-web.github.io/001_Public/MemoryGame/

۱. با اینترنت باز کنید. دکمهٔ «افزودن به آیفون» در بالای سمت راست، راهنمای کامل را نشان می‌دهد.

۲. در سافاری یا کروم، از گزینهٔ اشتراک‌گذاری، «افزودن به صفحهٔ اصلی» را انتخاب کنید. اگر گزینهٔ بازشدن به‌صورت برنامه وجود دارد، آن را فعال کنید و «افزودن» را بزنید.

۳. بازی را یک بار از نماد تازه با اینترنت باز کنید. منتظر پیام «آماده برای بازی آفلاین» بمانید. سپس حالت پرواز را روشن و دوباره از نماد بازی باز کنید.

دکمهٔ داخل بازی نمی‌تواند به‌تنهایی نماد را در آیفون نصب کند؛ تأیید نصب در فهرست خود آیفون انجام می‌شود. اگر این گزینه در اج آیفون دیده نمی‌شود، همان پیوند را در سافاری باز کنید. زبان فهرست‌های مرورگر و سیستم‌عامل را تنظیمات خود دستگاه تعیین می‌کند.

## امکانات

- ده مرحلهٔ آزاد با ۴، ۶، ۸، ۱۰، ۱۲، ۱۴، ۱۶، ۱۸، ۱۹ و ۲۰ جفت.
- هشت دسته: عددها؛ شکل‌ها و رنگ‌ها؛ رفت‌وآمد؛ وسایل روزمره؛ جانوران و طبیعت؛ خوراک و نوشیدنی؛ هاینبورگ و زندگی محلی؛ باغ درهم با دسته‌های انتخابی.
- حالت آرام، معمولی و چالش، بدون محدودیت زمان؛ مکث، ادامه، شروع دوباره، راهنما و بازی مرحله‌به‌مرحله.
- بازی روزانه بر اساس تاریخ محلی، بدون سرور؛ تغییر تاریخ فقط تنظیم دور بعدی را عوض می‌کند.
- گل یادگاری برای هر مرحله، سابقهٔ ۵۰ دور اخیر و بهترین نتیجهٔ شخصی.
- پیام خوش‌آمد دلخواه، دسته‌های دلخواه، نوشتهٔ بزرگ، تفاوت رنگ بیشتر، نمایش اختیاری زمان و کاهش حرکت.
- صدای فارسی اختیاری و پیش‌فرض خاموش؛ ۱۶۹ قطعه شامل نام ۱۵۰ کارت، ده پیام توسعه‌دهنده و نه راهنما و بازخورد. فایل صدا پس از ذخیرهٔ کامل به اینترنت یا صدای نصب‌شدهٔ دستگاه وابسته نیست.
- کنترل لمسی، صفحه‌کلید، نشانهٔ فوکوس و نام‌های دسترس‌پذیر فارسی. کلیدهای پیکان در چیدمان راست‌به‌چپ کار می‌کنند؛ ورود و فاصله کارت را انتخاب می‌کنند.
- بدون حساب، تبلیغ، ردیابی، سرویس ابری، قلم برخط یا دریافت تصویر از بیرون در زمان بازی.

نام برخی کارت‌ها از واژگان رایج دری مانند «موتر»، «بایسکل»، «چوکی»، «کیله» و «ناک» استفاده می‌کند. گفتار، صدای مصنوعی فارسی مدل «امیر» است؛ ادعای صدای انسان یا لهجهٔ اختصاصی دری ندارد. پیام خوش‌آمدِ دلخواه فقط نوشته است و به‌صورت گفتار تازه تولید نمی‌شود.

## آفلاین و نگه‌داری اطلاعات

جاوااسکریپت، قلم، نشان‌ها، عکس و صدای محلی با کارگر سرویسِ مخصوص همین پوشه ذخیره می‌شوند. پیام آماده‌بودن فقط پس از بررسی وجود تمام فایل‌های لازم نشان داده می‌شود. دکمهٔ بررسی دوباره، فایل‌های گم‌شده را هنگام اتصال بازیابی می‌کند. نسخه‌های تازه با دکمهٔ دریافت نسخهٔ تازه فعال می‌شوند.

برای نخستین آماده‌سازی به نشانی امن نیاز است. بازکردن مستقیم فایل اچ‌تی‌ام‌ال از پوشهٔ دانلود، روش نصب آفلاین نیست؛ بازی را از گیت‌هاب پیجز باز کنید. پس از پاک‌شدن داده‌های مرورگر، حذف برنامه، یا پاک‌سازی حافظه توسط دستگاه، آماده‌سازی با اینترنت باید تکرار شود. بازی نصب‌شده و زبانهٔ مرورگر ممکن است اطلاعات جداگانه داشته باشند. اطلاعات بین دستگاه‌ها همگام نمی‌شود.

تلاش، دو انتخاب معتبر از کارت‌های متفاوت و پیدا‌نشده است. لمس دوبارهٔ همان کارت، لمس کارت پیداشده، راهنما و لمس کارت سوم هنگام بررسی، تلاش اضافه نمی‌کند. زمان با نخستین انتخاب آغاز می‌شود، در مکث یا پس‌زمینه متوقف و در پایان ثابت می‌شود. دور ذخیره‌شده پس از بازشدن مجدد با مکث برمی‌گردد؛ انتخاب ناتمام بسته می‌شود و جفت‌های پیداشده باقی می‌مانند.

## معرفی مسئولانه

این بازی برای سرگرمی و تمرین است. وسیلهٔ پزشکی نیست و اختلال حافظه یا بیماری را تشخیص نمی‌دهد، پیشگیری نمی‌کند و درمان نمی‌کند. نتیجه‌ها فقط مربوط به همین بازی هستند.

## برای توسعه‌دهنده

The deployed game is dependency-free static HTML, CSS and browser JavaScript. No npm installation or build is needed to use the standalone folder. Upload this package inside `MemoryGame/`, then paste `PAGES_BUILD_SCRIPT.txt` into the repository-root `scripts/build.mjs`. The existing Pages workflow then checks and publishes the game. See [upload instructions](UPLOAD_INSTRUCTIONS.md) and [deployment](docs/DEPLOYMENT.md).

Optional local development: `python3 -m http.server 8080` from this folder, then open `http://localhost:8080/`. Localhost is a supported service-worker origin. Opening `index.html` as a `file://` URL does not support the module/PWA installation flow.

Optional automated tests, Node 24+: `node --test tests/*.test.mjs`. After updating the root build script: `npm run check` validates the full source, `npm test` runs the existing portfolio tests, and `npm run build` runs the game tests and publishes the game. There are no runtime npm dependencies. After changing a runtime asset run `node scripts/update-cache.mjs` inside this folder and rerun checks. The checked-in worker is ready for upload.

Edit `src/cards.js` to add card labels/art, `src/levels.js` for levels/messages and `src/config.js` for release identity. Keep at least 20 visually distinct identities per category; mixed mode deduplicates identical artwork. Update `assets/audio/transcripts.json` and regenerate the audio sprite with `scripts/generate-audio.py` after changing narrated text. That optional developer step uses Piper and FFmpeg; these tools/models do not ship in the browser game.

Replace the background only after verifying its location and reuse license. Update `assets/images/credits.json`, the native-language About screen and [attribution](docs/ASSET_ATTRIBUTION.md). Never hotlink the runtime background.
