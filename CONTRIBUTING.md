# Contributing

Read the root README, target app README and docs/ARCHITECTURE.md. Keep each app's runtime in applications/<slug>/ with relative URLs. Preserve compatible data keys, validate inputs/imports and record actual device/browser tests.

With Node 24 run npm ci --ignore-scripts, npm run check, npm test and npm run build. Do not commit dist, node_modules, credentials or user records. Preserve local asset/vendor licenses. Keep Sankey source unchanged unless explicitly authorized by the owner. New apps enter the existing shared workflow automatically.
